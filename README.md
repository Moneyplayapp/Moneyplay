# Money Play Android / Google Play

Abra esta pasta no Android Studio.

Antes do teste:
1. Substitua `serverUrl` em `MainActivity.kt` por seu domínio HTTPS.
2. Configure no Play Console os produtos `moneyplay_vip_ouro` e `moneyplay_vip_diamante`.
3. Implemente a verificação server-side da compra no backend.
4. Gere um `.aab` assinado em Release.

O projeto usa target/compile SDK 36.
